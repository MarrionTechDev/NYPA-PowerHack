COLUMNS
-------
name         type        allowed values / format        nulls?   notes
-----------  ----------  -----------------------------  -------  ---------------------
order_date   datetime    ISO 8601 (YYYY-MM-DD)          no
category     string      lowercase, trimmed             no       electronics, clothing, home
region       string      lowercase, trimmed             no       north, south, east, west
sales        float       >= 0                           no       rows with missing sales are dropped

RULES
-----
1. Column names are snake_case, lowercase, no spaces.
2. No duplicate rows.
3. Missing values: documented per column above (dropped / imputed / kept as NaN).
4. Dates parsed to real datetimes, not strings.
5. clean.csv is overwritten only by 01_clean.ipynb. Nobody edits it by hand.
