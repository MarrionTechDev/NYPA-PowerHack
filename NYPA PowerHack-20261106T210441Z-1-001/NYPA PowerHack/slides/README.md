# slides/

**Owner:** Presenter

## Purpose

Everything needed to present: the deck/slides and the demo script/Report.

## What goes in this folder

| File | What it is |
| :---- | :---- |
| The slide deck | Google Slides or PowerPoint. Keep one master file, not several versions. |
| `demo_script.md` (or a doc) | What to click and say during the live demo, in order, with timings. |
| A PDF export of the deck | Last thing before presenting, as a fallback if the slides won't open. |

## What this folder does

- Turns the Analyst's insights and the Dashboard lead's app into a story the judges can follow.  
- Holds the script so any teammate could run the demo if the Presenter can't.

## Suggested deck outline

1. Problem and the question we asked  
2. The data (source, size, what we cleaned)  
3. Approach (the pipeline in one diagram)  
4. Live demo  
5. Key insights (3 to 5, with numbers)  
6. Impact and next steps

## Rules

1. Insights on the slides must match `02_analysis.ipynb` exactly, so check numbers against the notebook.  
2. Write the demo script around what the dashboard actually does, and re-check it after the last code change.  
3. Rehearse with a timer at least twice.

## Done when

- [ ] Deck/ Slides are complete and matches the insights  
- [ ] Demo script is written and rehearsed  
- [ ] PDF copy of the deck is saved here  
- [ ] Deck and script are shared with the whole team
