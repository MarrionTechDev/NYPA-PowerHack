# backup/

**Owner:** Presenter (everyone contributes)

## Purpose
The safety net. If wifi, the app, or the laptop fails mid-presentation, everything needed to keep going is here.

## What goes in this folder
| File | What it is |
|---|---|
| `demo_recording.mp4` | Screen recording of the full demo, narrated or silent, 2 to 3 minutes. |
| Screenshots of every key view | One image per chart and page of the dashboard, named in demo order (`01_overview.png`, `02_trend.png`, ...). |
| `clean.csv` copy | So the dashboard can be run offline. |

## What this folder does
- Lets the Presenter play the recording or click through screenshots when the live demo breaks.
- Proves the project worked even if judges can't see it running.

## Rules
1. Record the video as soon as the dashboard works end to end, not at the last minute. Re-record if the app changes visibly.
2. Test that the video plays on the presenting laptop with wifi off.
3. Keep copies on the presenting laptop, not only on Drive.

## Done when
- [ ] Recording exists and plays offline
- [ ] Screenshots cover every part of the demo
- [ ] Everything is copied to the presenting laptop
